# Lowongan Pekerjaan: Junior Backend Developer

Kami sedang mencari seorang **Junior Backend Developer** yang antusias, memiliki fondasi kuat dalam pengembangan perangkat lunak sisi server (*server-side*), serta bersemangat untuk berkembang di ekosistem Cloud modern (**Amazon Web Services / AWS** dan **Google Cloud Platform / GCP**).

---

## 📌 Deskripsi Pekerjaan

Sebagai Junior Backend Developer, Anda akan bekerja sama dengan tim engineering kami untuk merancang, membangun, dan memelihara sistem backend yang andal. Anda akan berkesempatan mengelola REST API dan terlibat langsung dalam integrasi infrastruktur cloud.

---

## 🛠 Tanggung Jawab Utama

* **API Development:** Merancang, membangun, dan memelihara **RESTful API** yang aman, responsif, dan terdokumentasi dengan baik.
* **Integrasi Cloud:** Membantu tim dalam melakukan deployment, integrasi, dan pemeliharaan dasar aplikasi pada platform **AWS** dan **Google Cloud Platform (GCP)**.
* **Manajemen Database:** Mengelola query, mendesain skema, dan melakukan optimasi dasar pada database relasional maupun non-relasional.
* **Kolaborasi Tim:** Bekerja sama dengan tim Frontend, Mobile Developer, dan Product Manager untuk mengintegrasikan logika aplikasi.
* **Kualitas Kode & Testing:** Melakukan *debugging*, optimasi performa, serta menulis unit test dasar untuk menjaga keandalan sistem.

---

## 🎯 Kualifikasi & Persyaratan

### 1. Kualifikasi Umum
* Pendidikan minimal D3/S1 di bidang Teknik Informatika, Ilmu Komputer, Sistem Informasi, atau bidang terkait (atau pengalaman relevan setara).
* Pengalaman kerja **0 - 2 tahun** di bidang Backend Development (terbuka untuk *fresh graduate* yang memiliki proyek portofolio/pengalaman magang yang relevan).
* Kemampuan pemecahan masalah (*problem-solving*) yang baik dan keinginan kuat untuk terus belajar.

### 2. Keterampilan Teknis (Hard Skills)
* **Backend Framework & Language:** Menguasai salah satu bahasa pemrograman backend utama (seperti *Node.js/TypeScript*, *Python*, *Go*, atau *Java*).
* **RESTful API:** Memahami prinsip arsitektur REST API, HTTP methods, status codes, dan format data (JSON).
* **Pemahaman Cloud (AWS & GCP):**
  * Memahami konsep dasar layanan AWS (contoh: *EC2, S3, RDS, Lambda*).
  * Memahami konsep dasar layanan Google Cloud (contoh: *Compute Engine, Cloud Storage, Cloud Run*).
  * Familiar dengan konsep dasar *networking* dan keamanan cloud (IAM, Security Groups, VPC dasar).
* **Database:** Familiar dengan SQL (**PostgreSQL / MySQL**) dan/atau NoSQL (**MongoDB / Redis**).
* **Version Control:** Terbiasa menggunakan **Git** (GitHub / GitLab / Bitbucket).

### 3. Nilai Tambah (Nice-to-Have)
* Mengerti dasar-dasar kontainerisasi menggunakan **Docker**.
* Memahami alur kerja **CI/CD** sederhana (contoh: GitHub Actions, GitLab CI).
* Memiliki sertifikasi dasar cloud seperti *AWS Certified Cloud Practitioner* atau *Google Cloud Associate Cloud Engineer*.
